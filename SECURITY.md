# Security policy

## Reporting a vulnerability

Please report security vulnerabilities in these charts, or in the software they install, by email to
**security@stiravia.com**. Do not open a public GitHub issue.

Include, as far as you can:

- the chart and version (`helm list -A` shows them), and the Kubernetes version;
- a description of the issue and its impact;
- steps or values that reproduce it.

We will acknowledge your report and keep you informed while we work on a fix.

## Supported versions

Fixes are released as new chart versions. Please upgrade to the latest version of a chart before reporting.

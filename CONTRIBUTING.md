# Contributing

The charts in this repository are developed in a private repository and published here. This repository does not
accept pull requests: changes made here would be overwritten by the next release.

You are welcome to:

- report bugs and ask questions by [opening an issue](https://github.com/stiravia/helm-charts/issues/new/choose);
- suggest improvements to a chart in an issue.

To report a security vulnerability, see [SECURITY.md](SECURITY.md) instead.
